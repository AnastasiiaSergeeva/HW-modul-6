# 💇‍♀️ Виртуальный стилист

Приложение для подбора причёски и цвета волос на чистом HTML/CSS/JavaScript — без сборщиков и зависимостей.

## Возможности

- **Режим «Моё фото»**: загрузите свою фотографию — причёска сама находит лицо
  (детектор pico.js, MIT, работает целиком в браузере) и садится по его контуру:
  задний слой волос обрамляет лицо через маску, чёлка отбрасывает мягкую тень на лоб.
  Подгонка вручную: перетаскивание мышью/пальцем, ползунки «Размер», «Ширина», «Наклон»,
  колесо мыши — масштаб. Результат можно скачать как PNG.
  Фото обрабатывается только в браузере и никуда не отправляется.
- Реалистичная отрисовка волос: градиенты света и тени, отдельные пряди, блики,
  мягкие края и выбившиеся волоски.
- **ИИ-анализ лица** (целиком в браузере): по найденному лицу автоматически
  определяются форма лица (замер ширины лба/скул/челюсти и длины по маске кожи)
  и цветотип (тон кожи, волос, контраст → весна/лето/осень/зима); подходящие
  причёски и цвета подсвечиваются ✨.
- **ИИ-фотореализм (экспериментально)**: нейросеть Google Gemini перерисовывает
  причёску прямо на фото. Нужен свой API-ключ с aistudio.google.com (в этом
  режиме фото отправляется в Google). Работает при открытии index.html
  напрямую или с локального сервера.
- 8 причёсок (пикси, каре, длинные, каскад, кудри, хвост, пучок, ёжик) с живым превью на SVG-аватаре
- 10 готовых цветов волос + выбор произвольного цвета
- 5 тонов кожи
- Рекомендации причёсок по форме лица (овал, круг, квадрат, сердце, вытянутое) — подходящие варианты отмечаются ✨
- Кнопка «Случайный образ» (учитывает выбранную форму лица)
- Сохранение любимых образов и текущего выбора в localStorage

## Запуск

Просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
cd hairstyle-app
python3 -m http.server 8000
# затем откройте http://localhost:8000
```
