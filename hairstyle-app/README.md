# 💇‍♀️ Виртуальный стилист

Приложение для подбора причёски и цвета волос на чистом HTML/CSS/JavaScript — без сборщиков и зависимостей.

## Возможности

- **Режим «Моё фото»**: загрузите свою фотографию — причёски и цвет накладываются прямо на неё.
  Причёску можно двигать мышью/пальцем, менять размер (ползунок или колесо мыши) и наклон,
  а результат скачать как PNG. Есть кнопка авто-подгонки по лицу (если браузер поддерживает FaceDetector).
  Фото обрабатывается только в браузере и никуда не отправляется.
- 8 причёсок (пикси, каре, длинные, каскад, кудри, хвост, пучок, ёжик) с живым превью на SVG-аватаре
- 10 готовых цветов волос + выбор произвольного цвета
- 5 тонов кожи
- Рекомендации причёсок по форме лица (овал, круг, квадрат, сердце, вытянутое) — подходящие варианты отмечаются ✨
- Кнопка «Случайный образ» (учитывает выбранную форму лица)
- Сохранение любимых образов и текущего выбора в localStorage

## Запуск

Просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
cd hairstyle-app
python3 -m http.server 8000
# затем откройте http://localhost:8000
```
